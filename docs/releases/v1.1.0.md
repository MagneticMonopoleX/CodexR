# CodexR v1.1.0

The first stable-labeled release of CodexR, following personal testing of the current build. CodexR is an unofficial Android client for using Codex with a controlled root shell, not an OpenAI product. Compatibility with every device, Android build, and root manager is not guaranteed.

## Changes since v1.1.0-beta.1

- Commands, tool results, and AI screenshots are folded by default into compact action rows. Tap to expand full selectable output and attachments; Copy remains available while folded.
- Matching adjacent calls and results share one row. Failure, denial, and interruption statuses remain visible, and an expanded row stays expanded when its result arrives.
- Shell actions use structured function calls and paired outputs. Stop, retry, and queued follow-ups retain their tool boundaries across long conversations.
- A draggable background overlay shows the latest message or work status, with Stop and Follow up controls. Enable it in the sidebar and grant Android's display-over-other-apps permission.
- Device tests use a separate application package so test cleanup does not erase the normal CodexR installation's chats or credentials.

Existing features include ChatGPT OAuth, encrypted API-key access, model and reasoning selection, multiple chats, usage checks, themes, Markdown and offline LaTeX, attachments, screen capture, and approval-controlled root execution.

## Download and upgrade

Download **CodexR-v1.1.0.apk** and install it over the earlier version. Android 7.0+ is required; root tools also require a working `su` and `setsid` implementation.

```bash
adb install -r CodexR-v1.1.0.apk
```

The package remains `com.example.codexmobile`, with version code **3**. The non-debuggable APK uses the same existing development certificate as the previous published preview. A dedicated production-signing setup is still pending. No signing key or credentials are included in the release.

Do not uninstall or clear app data to upgrade: that removes local chats, attachments, and saved sign-in. A copy signed with another certificate cannot be updated in place with this APK; retain it until you have a data-migration plan.

Verify the APK against **SHA256SUMS.txt** from the release assets.

## Safety and setup

- Root commands can damage the device or erase data. Approval-required mode is recommended. Stop does not undo completed changes, and deliberately detached processes can escape cancellation.
- Session approval includes subsequent root commands and AI screen captures in that chat. It resets when the app process restarts. Full-access mode persists until disabled.
- Screenshots may contain private information. Screen capture does not unlock the device or bypass protected windows.
- Allow notifications and configure unrestricted battery use for long background tasks. Android and vendor background limits still apply; interrupted root work is not silently restarted.
- ChatGPT backend behavior can change. API billing and usage are separate from ChatGPT subscription usage.

## Verification

All 36 local unit tests passed, along with debug and release Android lint. The release APK passed metadata, alignment, and signature checks; its signing certificate matches the published beta. The folded-action UI previously passed two isolated device tests on the connected Lenovo tablet; the maintainer subsequently reported the current version stable after testing. This release does not claim a new full device-test run or universal compatibility.
