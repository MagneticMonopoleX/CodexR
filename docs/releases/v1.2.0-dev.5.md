# CodexR v1.2.0-dev.5

Prerelease · version code 8

## Changes

- Automatic context compaction keeps long conversations within the model's context budget while preserving the full local, searchable transcript. Manual **Compact now** is available in Conversation storage.
- Uses native compaction where available; explicitly unsupported backends fall back to a tool-free model-generated summary. Summaries can lose detail, and compaction consumes model quota.
- Export a specific chat from its sidebar **⋮ → Export chat** menu, or export the active chat from Conversation storage. ZIP archives include the transcript and referenced attachments, not authentication credentials or root grants.
- Import an archive as a separate chat, with validation and attachment limits. Importing never starts execution or overwrites an existing chat.
- Immediate client-side steering: a follow-up interrupts HTTP inference and continues with the new message. Interrupted text stays in local history but is excluded from the continuation context.
- Running commands are not cancelled or replayed by steering. Follow-ups wait for their result; Stop still cancels the whole turn. The floating overlay uses the same behavior.

## Install safely

Install `CodexR-v1.2.0-dev.5.apk` over a previous build signed with the same maintainer development certificate. Do not uninstall or clear app data. A different signing certificate cannot update in place; uninstalling to bypass that mismatch deletes local data.

Verify the download with `SHA256SUMS.txt`. This APK is non-debuggable, but uses the existing development signing certificate rather than a dedicated production key.

Root access can permanently damage the device or erase data. Keep approval-required mode enabled unless you accept the risks. This is an unofficial client and a prerelease; backend compatibility can change. Client-side steering is not the backend `response.steer` protocol.
